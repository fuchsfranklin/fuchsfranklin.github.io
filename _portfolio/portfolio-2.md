## Project Overview

###### _(R and Shiny-based Programming Project)_

Together with Tiffany Hsieh and Bowen Chen, I built this R Shiny app to give some intuition for survival analysis, from both the theory side and the applied side. We'd found a publicly available Moderna vaccine survival dataset on GitHub that we wanted to dig into, so the app first walks through the basic survival analysis ideas without much math and then applies them to that dataset.
